# أَثَر | ATHAR
### المنصة الرقمية للأناشيد والذاكرة البصرية لمنظمة رِحلة ومشروع غرسة
> **«لكل أثر حكاية، ولكل حكاية صوت»**

---

## 📖 1. فكرة المشروع ورؤيته
**«أَثَر»** هي منصة ويب عربية رقمية متكاملة صُممت لتكون الأرشيف الصوتي والبصري الموحد لتوثيق مبادرات **منظمة رِحلة للتنمية المستدامة** والمبادرة الوطنية **مشروع غرسة** لمكافحة التصحر والتشجير في ليبيا.

تجمع المنصة بين:
1. **المشغل الصوتي المستمر (Persistent Audio Player)**: ألبوم غرسة الإنشادي الأول متضمناً 4 أناشيد رسمية مصورة (`عناق الجذور`، `غداً شجرة`، `غرسة الأمل`، `وعد السنابل`) بالإضافة إلى مسارات استوديو إضافية، مع ميزة استمرار الصوت دون انقطاع أثناء تصفح كامل أقسام الموقع.
2. **ذاكرة غرسة ورِحلة (Visual Memory Archive)**: معرض تحريري تفاعلي يضم **33 صورة ميدانية موثقة** لسواعد المتطوعين والطلاب والأنشطة في المدارس والمدن، مزود بنافذة عرض مكبرة (Lightbox) تدعم التنقل السلس والتصنيف الموضوعي.
3. **ألبوم رِحلة المستقبلي**: واجهة مهيأة معمارياً لاستيعاب الإصدارات الإنشادية القادمة لمنظمة رِحلة («أصداء القرى») دون الحاجة لإعادة كتابة الكود.
4. **التكامل المؤسسي والخصوصية**: روابط موثقة للمواقع الرسمية ([rehlaa.org](https://rehlaa.org) و [gharsa.ly](https://gharsa.ly)) مع الالتزام التام بعدم نشر أي بيانات حساسة أو معرّفات بيومترية.

## 🛠️ 2. البنية التقنية (Technology Stack)
- **النواة**: HTML5 دلالي (Semantic HTML) + Vanilla JavaScript (ES Modules حديثة ونقية).
- **التصميم والأنماط (CSS)**: Vanilla CSS معيارية مع Design Tokens مخصصة (تحكم فائق في الأداء، زجاجية ناعمة Glassmorphism، ودعم كامل للوضع الداكن المريح للعين).
- **الاتجاه والخطوط**: دعم كامل لاتجاه القراءة من اليمين إلى اليسار (`dir="rtl"`) مع خطوط `Cairo` و `Tajawal` العربية فائقة الوضوح.
- **أداة البناء والخادم**: [Vite](https://vitejs.dev/) لتوفير سرعة تحميل قصوى وتوليد حزمة إنتاج خفيفة جداً (أقل من 65 كيلوبايت كود مجمع ومضغوط).
- **الوصولية (A11y)**: التزام بمعايير WCAG AAA وتباين لوني معتمد، ودعم كامل للتنقل عبر لوحة المفاتيح واختصارات المسافة والأسهم.

## 🚀 4. كيفية تشغيل المشروع محلياً

### المتطلبات المسبقة:
- توفر بيئة Node.js (الإصدار 18 أو أحدث).

### خطوات التشغيل:
1. افتح موجه الأوامر (PowerShell أو Terminal) في مجلد المشروع:
   ```powershell
   cd "c:\Users\DELL\أَثَر  ATHAR"
   ```
2. تثبيت الحزم (عند الحاجة):
   ```powershell
   npm install
   ```
3. تشغيل خادم التطوير السريع:
   ```powershell
   npm run dev
   ```
   سيظهر لك رابط مباشر، عادة: `http://localhost:3000` أو `http://localhost:5173`.

4. معاينة حزمة الإنتاج:
   ```powershell
   npm run build
   npm run preview
   ```

## 📝 5. دليل تحديث وإدارة المحتوى (لفريق العمل)

تم تصميم المنصة وفق مبدأ **فصل البيانات عن واجهة العرض**، بحيث يمكن لأي عضو في الفريق تعديل المحتوى عبر ملفات بيانات سهلة وبسيطة دون لمس كود الواجهة.

### أ. كيفية إضافة نشيد جديد:
1. ضع الملف الصوتي أو المرئي في المجلد:
   `public/media/gharsa/tracks/`
2. افتح الملف: [`src/data/tracks.js`](file:///c:/Users/DELL/أَثَر%20%20ATHAR/src/data/tracks.js)
3. أضف كائن النشيد إلى مصفوفة `tracks`:
   ```javascript
   {
     id: 'track-7',
     trackNumber: 7,
     title: 'اسم النشيد الجديد',
     englishTitle: 'New Nasheed Name',
     duration: '02:30',
     durationSeconds: 150,
     audioSrc: '/media/gharsa/tracks/your-audio.mp3',
     videoSrc: '/media/gharsa/tracks/your-video.mp4', // أو null إذا كان صوتياً فقط
     format: 'MP3 Studio Master',
     fileSize: '4.5 MB',
     theme: 'موضوع النشيد',
     description: 'وصف موثوق لموضوع النشيد ومناسبته.',
     lyricsPreview: 'مقطع من الكلمات...',
     status: 'available'
   }
   ```

### ب. كيفية إضافة صور جديدة للمعرض:
1. ضع الصور المعتمدة للنشر في:
   `public/media/gallery/`
2. افتح الملف: [`src/data/gallery.js`](file:///c:/Users/DELL/أَثَر%20%20ATHAR/src/data/gallery.js)
3. أضف بيانات الصورة إلى مصفوفة `GALLERY_ITEMS`:
   ```javascript
   {
     id: 'photo-34',
     fileName: 'image_name.jpg',
     src: '/media/gallery/image_name.jpg',
     width: 1440,
     height: 960,
     aspectRatio: '3:2',
     category: 'غرس الأشجار والشتلات', // أو 'حملات المدارس والطلاب' / 'روح التطوع والميدان'
     title: 'توثيق فعالية تشجير مدرسة ...',
     approved: true // تعيينها إلى false يخفي الصورة من العرض العام
   }
   ```

### ج. تفعيل ألبوم رِحلة عند صدوره:
في ملف [`src/data/tracks.js`](file:///c:/Users/DELL/أَثَر%20%20ATHAR/src/data/tracks.js)، غيّر خاصية `isUpcoming` في كائن `REHLA_ALBUM_TEASER` إلى `false`، وأضف مصفوفة `tracks` الخاصة برِحلة بنفس صيغة ألبوم غرسة.

## 🌐 6. النشر السحابي (Deployment)

### النشر عبر Vercel:
1. ارفع المشروع إلى مستودع GitHub.
2. اربط المستودع في منصة [Vercel](https://vercel.com).
3. اختر الإعدادات التلقائية: Framework: `Vite`، Build Command: `npm run build`، Output Directory: `dist`.

### النشر عبر GitHub Pages:
1. نفّذ أمر البناء: `npm run build`.
2. ارفع محتويات مجلد `dist` إلى فرع `gh-pages` في مستودع GitHub.

## 🔒 7. سياسة الخصوصية وحقوق المحتوى
- **حماية القُصّر والمتطوعين**: لا تتضمن المنصة أي تقنيات للتعرف على الوجوه أو جمع القياسات الحيوية.

- **الحق في الاستبعاد**: يدعم النظام إخفاء أي صورة فوراً بتعديل خاصية `approved: false` في ملف البيانات دون حذف الأصل من الأرشيف.
